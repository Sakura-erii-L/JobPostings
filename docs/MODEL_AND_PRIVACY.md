# 模型和隐私边界

选定招聘群中的所有受支持消息都会参与模型分类。文本、合并转发条目、图片 OCR、二维码结果、公开网页正文和文档提取文本不会因为本地关键词规则而提前丢弃。

默认不脱敏。启用脱敏后，手机号、邮箱、微信号、QQ 和身份证号会替换为稳定占位符；消息正文及发送给模型的 metadata 都会处理，本地原始消息不被覆盖。详细地址和联系人姓名不做自动实体识别，使用云模型时应按需要人工复核。

模型输入不包含系统工具权限。网页正文和群聊文本始终作为不可信数据，不能改变系统提示、权限和任务流程。

每日默认配额：输入 1,000,000 Token，输出 200,000 Token。任一达到 80%时告警，达到 100%时暂停新请求。
